<p class="lead">Tobokachi est développé par un seul développeur indépendant. Si quelque chose ne fonctionne pas, ou si vous avez une idée pour l'appli, écrivez-moi. Je lis tous les messages.</p>

## Contact

E-mail : **[vanitcode@icloud.com](mailto:vanitcode@icloud.com)**

Pour trouver le problème rapidement, indiquez-moi l'appareil que vous utilisez (iPhone ou iPad, et sa version d'iOS) et ce que vous faisiez à ce moment-là. Une capture d'écran aide beaucoup.

## Questions fréquentes

### Je n'ai pas reçu le rappel du jour

Vérifiez que les notifications sont autorisées pour Tobokachi dans **Réglages → Notifications → Tobokachi**, et que vous avez choisi une heure d'étude dans l'appli. Le rappel arrive à cette heure-là, quand la feuille du jour est prête.

### Mes fiches n'apparaissent pas sur mon autre appareil

Tobokachi se synchronise avec votre propre iCloud. Les deux appareils doivent utiliser le même compte Apple, avec iCloud activé pour Tobokachi (**Réglages → votre nom → iCloud**). Ouvrez l'appli sur les deux appareils et laissez-lui quelques minutes.

### Comment imprimer la feuille ?

Ouvrez la feuille du jour dans l'appli, touchez **Partager** puis choisissez **Imprimer**. Vous pouvez aussi envoyer le PDF sur un Mac par AirDrop et l'imprimer depuis celui-ci.

### Comment envoyer la feuille sur ma tablette à encre électronique ?

Touchez **Partager** sur la feuille et choisissez l'appli de votre tablette. La plupart des tablettes à encre électronique ont une appli iPhone qui accepte les PDF. Certaines permettent aussi de leur envoyer des documents par e-mail.

### Quels fichiers CSV puis-je importer ?

N'importe quel fichier CSV. La première ligne est lue comme les noms des colonnes. Vous choisissez ensuite quelle colonne contient le mot, laquelle contient la traduction et, si vous le souhaitez, laquelle contient le paquet.

### Comment supprimer mes données ?

Supprimer l'appli efface les données stockées sur cet appareil. Pour supprimer aussi la copie dans votre iCloud, allez dans **Réglages → votre nom → iCloud → Gérer le stockage** et supprimez les données de Tobokachi. Tobokachi ne stocke rien ailleurs : voir la [politique de confidentialité](../privacy/).
